# imapex

A tool to export a mailbox through IMAP and save it to eml files

## Usage 

```bash
Usage: imapex [OPTIONS] --username <USERNAME> --password <PASSWORD> --server <SERVER> --destination <DESTINATION> --mailbox <MAILBOX>

Options:
  -u, --username <USERNAME>        
  -p, --password <PASSWORD>        
  -s, --server <SERVER>            
  -d, --debug                      
      --destination <DESTINATION>  
  -l, --limit <LIMIT>              
  -m, --mailbox <MAILBOX>          
  -r, --remove                     
  -h, --help                       Print help
```
